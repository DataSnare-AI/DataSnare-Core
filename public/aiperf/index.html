Threshold methodology

Findings require sustained pressure: at least three samples and at least 30 seconds when timestamps permit. Thresholds are operational heuristics, not universal capacity limits.

  • CPU total: warning ≥ 80%, critical ≥ 95%.
  • Processor queue: warning above 2 per logical processor when processor count is known; otherwise above 2.
  • Committed memory: warning ≥ 80%, critical ≥ 90%; available memory warning below 500 MB.
  • Pages/sec: warning ≥ 20, interpreted with memory pressure.
  • Disk latency: warning ≥ 20 ms, critical ≥ 50 ms; disk queue warning above 2.
  • Network utilization: warning ≥ 80% of current bandwidth; interface errors and TCP resets warn when sustained above zero.
  • System Diagnostics ETW loss: warning above 0%, error above 5%, critical above 20%.
